Icone per la schermata "Categorie e Tag".

Il caricamento avviene in DashboardPanel.java con getResource(...).
Per sostituire un'icona, mantieni lo stesso nome file PNG oppure aggiorna la mappatura nel metodo getClassificationIconPath(...).
I file sono duplicati anche in bin/ per consentire l'avvio immediato in ambienti che non copiano automaticamente le risorse non-Java.
